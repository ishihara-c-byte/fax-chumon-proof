# FAX注文書 校正ツール

法人弁当ユーザー様向け「FAX注文書」PDFを、メニューパンフレット中面PDFとカレンダーを正として自動で校正するStreamlitアプリです。

## チェック内容
| 項目 | 照合の相手 |
|---|---|
| ① 年・月・期間(例: 12/1〜12/31) | カレンダー |
| ② 曜日に合った日付か / 店休日(グレーの日付) | カレンダー・中面 |
| ③ 旗日の文字(フェア名・プレミアム・スペシャル)、日付の黒地、贅沢版の混ぜご飯 | 中面 |
| ④ イベントWeekの表記と期間 | 中面 |

- 店休日は店舗ごとに違うことがあるため「要確認」で表示します。
- 店休日(グレー)のマスは③の対象外です。
- 白いフタなどで隠れている文字は、ページを画像にして確認し、見えていないものは無視します。

## 使い方
1. 中面PDFをアップロード → 読み取った旗日・混ぜご飯・店休日・イベント期間を確認(表で修正可)
2. FAX注文書PDF(1ページ=1店舗、複数ファイル可)をアップロード
3. 「校正をはじめる」→ 結果を確認、Excelでダウンロード

## ファイル
- `app.py` … 画面
- `proof_core.py` … PDFの読み取りと照合のロジック
- `requirements.txt` … 必要なライブラリ
